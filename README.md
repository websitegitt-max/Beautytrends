# Atelier Élan — Haute Unisex Hair & Aesthetics

Production-grade frontend for Atelier Élan featuring:
- **Zero Pricing Structure**: Focuses on bespoke luxury consultation over commercial price menus.
- **Dedicated Men's & Women's Collections**: Structured cards with photos and service narratives.
- **Master Stylist Showcase**: 3-frame editorial profile highlighting master directors.
- **Live Google Map Integration**: Exact location in Andrahalli Main Rd, Bengaluru with dual UI overlays.

## Running Locally

```bash
npm install
npm run dev
```

## Deployment to GitHub Pages
Push to GitHub and enable **GitHub Actions** under Settings > Pages.
